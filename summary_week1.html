1. TỔNG HỢP CÁC FILE ĐÃ TẠO VÀ TÁC DỤNG

Trong Tuần 1, phân hệ Sinh dữ liệu AI có nhiệm vụ xây dựng khung thẩm định dữ liệu và prompt mẫu nhằm giúp các thành viên nhóm làm Game (Thế Anh, Sơn Nguyễn) và Giao diện (Sơn Phạm) có thể chạy thử độc lập. Chi tiết các file đã tạo:

Tên tệp Nội dung xây dựng Lý do tạo & Tác dụng đối với dự án
ai_generate.py - Khung kiểm tra Pydantic Models.
- Hàm bóc tách Markdown fence: strip_markdown_fence().
- Hàm chia 3 phần: split_text_into_three_parts().
- Hàm đọc, kiểm định và lưu file JSON. 		Người gác cổng dữ liệu: Ngăn chặn dữ liệu lỗi do AI sinh ngẫu nhiên làm sập ứng dụng. Bắt buộc câu điền từ phải có duy nhất một ký hiệu ___; câu trắc nghiệm phải đủ 4 options và đáp án 0..3. Là khung xương để gắn API tuần 2.
prompts.py - 3 mẫu prompt riêng cho 3 game (Điền từ, Nối từ, Trắc nghiệm).
- Hỗ trợ cả 2 môn: Tiếng Anh và Triết học.
- Hàm tiện ích lấy prompt theo phần và môn. 		Ép khuôn và chống bịa đặt: Ràng buộc AI chỉ sử dụng nội dung có trong bài, không bịa kiến thức bên ngoài (chống hallucination). Ép AI trả lời thuần định dạng JSON, không kèm lời chào hay văn bản thừa.
data/sample_chapter.json File JSON mẫu viết tay hoàn chỉnh cho môn Triết học (Chương 2: Chủ nghĩa duy vật biện chứng), gồm đủ 3 phần chơi. Hợp đồng dữ liệu chung (Mốc M1): Bàn giao ngay cho nhóm Game và UI nạp dữ liệu để dựng giao diện song song mà không cần đợi kết nối AI thật. Dùng làm dữ liệu dự phòng (fallback) khi mất mạng/hết API.
.env.example
.gitignore		 - .env.example: Mẫu biến môi trường GEMINI_API_KEY.
- .gitignore: Danh sách chặn file bí mật và cache. 		Bảo mật thông tin: Tuân thủ quy định bảo mật của dự án (Mục 8.2), tuyệt đối không đẩy API key cá nhân lên GitHub repo chung.
requirements.txt Khai báo các thư viện: pydantic, python-dotenv, google-generativeai. Chuẩn hóa môi trường: Giúp các thành viên trong nhóm và môi trường máy chủ cài đặt đúng phiên bản thư viện cần thiết.
test_week1.py Kịch bản kiểm thử tự động (Unit Test) kiểm tra tính hợp lệ của schema, thử bẫy các ca vi phạm quy tắc. Kiểm thử tối thiểu (Mục 7.6): Bằng chứng xác nhận code hoạt động chính xác 100% trước khi tạo Pull Request vào nhánh chính của nhóm.

2. MỨC ĐỘ TUÂN THỦ QUY TẮC BÁO CÁO KỸ THUẬT

Quy tắc kỹ thuật theo tài liệu thiết kế Vị trí trong mã nguồn Đánh giá
Môn học: Chỉ nhận english hoặc philosophy (Mục 6.2) ai_generate.py (ChapterModel) ĐẠT
Bắt buộc có đúng 3 phần với thứ tự part: 1, 2, 3 (Mục 6.2) ai_generate.py (validate_structure) ĐẠT
Game 1: Câu hỏi phải chứa đúng một ký hiệu ___ (Mục 6.2) ai_generate.py (FillBlankItem) ĐẠT
Game 2: Thuật ngữ (term) và định nghĩa không được rỗng (Mục 6.2) ai_generate.py (MatchingItem) ĐẠT
Game 3: Đúng 4 options, đáp án là chỉ số nguyên từ 0..3 (Mục 6.2) ai_generate.py (QuizItem) ĐẠT
Tự động lọc bỏ Markdown Code Fence ```json (Mục 6.2) ai_generate.py (strip_markdown_fence) ĐẠT
Chia văn bản thành 3 phần cho 3 game (Mục 7.2) ai_generate.py (split_text_into_three_parts) ĐẠT
Prompt riêng cho từng game, cấm bịa kiến thức ngoài (Mục 7.2, 11) prompts.py ĐẠT
Bảo mật: Không để API key trong mã nguồn (Mục 2.2, 8.2) .env.example, .gitignore ĐẠT
